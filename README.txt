FOREVER COMPANION v1.0 (18. 10. 2026)
Neoficiální fanouškovská PWA pro WoW: Forever, česky.

INSTALACE GITHUB PAGES:
1) Na GitHubu vytvoř veřejný repozitář, například wow-forever-companion.
2) Do KOŘENE nahraj obsah tohoto ZIPu (ne samotný ZIP).
3) Settings → Pages → Deploy from a branch → main → /(root) → Save.
4) Otevři adresu https://TVUJ-UCET.github.io/wow-forever-companion/
5) iPhone / Safari → Sdílet → Přidat na plochu.

FUNKCE:
- správa postav a rolí Hordy, volba hlavní postavy, profese
- 65 Legacy výzev (body za level classy se vyhodnocují automaticky)
- doporučení pro aktuální level a zvolenou roli
- vlastní úkoly
- offline podpora po první návštěvě, instalovatelná PWA
- export/import zálohy JSON
- bez backendu, bez registrace a bez online synchronizace

POZNÁMKY:
Výsledky se ukládají pouze v prohlížeči do localStorage.
Zdroj informací: oficiální články Blizzardu dostupné do 18. 10. 2026.
Beta hodnoty se mohou změnit. Aplikace není spojena s Blizzardem.
