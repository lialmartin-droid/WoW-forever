FOREVER COMPANION v2.1 – Deník postav (19. 10. 2026)

Jde o neoficiální českou webovou aplikaci pro WoW Forever.
ŽÁDNÉ DEMO POSTAVY ANI AUTOMATICKÉ PŘIDÁNÍ POSTAV.

Funkce:
- Všech 9 class Hordy (Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock, Druid)
- Založ libovolný počet vlastních postav i stejné classy
- Každá postava má vlastní kroniku událostí (datum, typ, nadpis a popis)
- Každá postava může mít více buildů, rozdělení bodů a speciální rotace
- Rotace pro opener, jeden cíl a AoE, ke každému buildu vlastní poznámky
- Offline deník talentů počítá body podle plánovaného levelu a maximum ranku.
  NEPOKRÝVÁ herní strom (tier, pozice, prerequisites) – pro všech 9 class je k dispozici
  odkaz na aktuální online talent kalkulačku a možnost uložit si její URL.
- Legacy tracker všech 65 výzev, osobní úkoly a průvodce
- JSON export / import (včetně deníku, talentů a rotací)
- Starší údaje z v1 aplikace zůstanou zachovány: localStorage klíč se nemění.

GitHub Pages:
1. Rozbal ZIP na PC nebo nahraj jeho obsah do kořene repozitáře.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Na iPhonu otevři HTTPS adresu v Safari, Sdílet → Přidat na plochu.

Ukládání: pouze localStorage konkrétního prohlížeče / domény. Exportuj zálohu
před vymazáním dat nebo změnou adresy webu. Žádný server není potřeba.
Beta pravidla a talenty se mohou měnit. Projekt není propojen s Blizzardem.
